RUN STOPPED

Windows security blocked the reasoning runtime

Avast or another security product can report AkuSidecar as ready while sandboxing the Codex process it starts. Do not delete your %USERPROFILE%\.codex folder or its SQLite files.

  1. Allow the official AkuBrowser release or add a narrow exception for AkuBrowser.
  2. Stop every running installed or portable AkuSidecar.exe.
  3. Download and extract the matching portable bundle, then run Start-AkuBrowser.ps1.

Do not run installed and portable runtimes together. This manual fallback must be started again after Windows restarts.
